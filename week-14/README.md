# Week 14 — Part A: AI Governance Gap Assessment

**Domain 6 · AI Governance · HerNetIQ AI Security Fellowship, Cohort 1**

## Deliverable

The primary deliverable for this folder is the [Governance Gap Assessment](./governance-gap-assessment.md).

I reviewed the NovaPay AI governance policy, selected code and configuration files, model card, audit log, architecture and incident records in the provided [NovaPay case repository](https://github.com/AibinuolaDamilola/hernetiq/tree/main/novapay-ai-core). I compared the stated controls with what is visible in the reviewed implementation and recorded four evidence-backed findings.

The assessment includes:

- Assessment scope and review approach using the four NIST AI Risk Management Framework functions.
- Four standalone findings with policy claims, observed evidence, severity, relevant OWASP LLM Top 10 mapping where applicable, and remediation with an owner and timeframe.
- Inline citations to policy sections, code lines, audit-log records and incident evidence.
- A regulatory exposure table using the control areas and conditional regulatory mappings covered by the fellowship notes.
- Overall verdict, prioritised remediation plan, evidence-verification record and Career Passport evidence notes.

## Evidence basis and limitations

The findings are based on the cited GitHub repository and the provided S28/S29 notes and Evidence Brief A requirements. The assessment is a **source-level review**: I inspected the code and audit records but did not conduct live production testing or claim to reproduce either incident. The report separates what the evidence shows from unresolved root causes and legal applicability questions.
