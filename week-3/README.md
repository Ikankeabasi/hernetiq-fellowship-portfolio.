# Week 3 – Cloud Security & IAM

This week focused on Identity and Access Management (IAM), least privilege, role assumption, and CloudTrail forensic analysis.

## Learning Objectives

- Understand AWS IAM users, roles, and policies.
- Apply the Principle of Least Privilege.
- Identify insecure IAM permissions.
- Analyse CloudTrail logs to reconstruct an attack timeline.
- Develop security recommendations based on forensic evidence.
