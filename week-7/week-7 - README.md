# Week 7 — Application & API Security

## HerNetIQ AI Security Fellowship · Cohort 1 · 2026

**Domain:** Application & API Security

Week 7 focuses on understanding how applications communicate with backend systems through APIs and how security failures can occur at the application and API layers.

This week covers API fundamentals, HTTP request anatomy, API security risks, access-control failures, authentication, rate limiting, AI-specific API risks, and practical investigation of application and API security issues.

## Learning Objectives

By the end of Week 7, I should be able to:

- Explain what an API does.
- Identify the main components of an HTTP request.
- Understand common API security risks.
- Distinguish authentication from authorization.
- Explain Broken Object Level Authorization (BOLA).
- Understand why client-supplied identifiers require server-side verification.
- Explain the purpose of rate limiting.
- Understand Denial of Wallet as an AI-specific security and financial risk.
- Analyse what an API trusts and what the server should independently verify.
